# Учебные задания на Java

Небольшая консольная программа с тремя заданиями:

1. Сравнение двух целых чисел и арифметические операции. Деление целочисленное; деление на ноль обрабатывается отдельно.
2. Сравнение двух строк с учётом регистра.
3. Вывод чётных чисел из заданного массива от 1 до 10.

## Запуск

Нужен JDK 11 или новее, команды `java` и `javac` должны быть доступны в терминале. Из корня репозитория выполните:

```sh
javac src/*.java
java -cp src Main
```

В меню введите номер задания: `1`, `2` или `3`. Затем следуйте подсказкам. Для повторного выбора запустите программу ещё раз.
